    Behaviour

    When a Cloudflare/Turnstile, reCAPTCHA or hCaptcha check blocks the page, this model solves just the challenge and the main model continues. It is built and tested for CaptchaKraken v1.2, a free local CAPTCHA model (about 7 GB of GPU memory, 16k context). Other vision models are experimental.

    No CAPTCHA solver found. Install it with ollama pull hf.co/CaptchaKraken/CaptchaKraken-v1.2-GGUF:Q4_K_M, start Ollama with OLLAMA_CONTEXT_LENGTH=16384, then click Refresh model lists in the model menu. Setup guide

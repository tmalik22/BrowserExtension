Common questions

The side panel says "Start the agent server"

The extension needs its small local server running. Download the server zip from the latest release, unzip it, and run Start Browser Agent.cmd (Windows) or ./start.sh (macOS/Linux). Keep that window open. It needs Node.js 20+.

How do I pair the extension with the server?

Click Pair this browser in the side panel. The panel and the server window both show a 6-digit code. If they match, click Codes match in the panel and type y in the server window. Only approve a code you started pairing for yourself.

My Ollama / LM Studio models don't appear

Start Ollama or LM Studio, then open the model menu in the side panel and click Refresh model lists. Pick your model there: a detected model is never chosen automatically.

How do I use a cloud model?

Open the side panel, then ⚙ Settings → API keys, and paste your key. The side panel passes it to the server on your computer, which saves it there and sends it to that provider with each request. The extension doesn't keep it, and the full key is never sent back to the browser (only its last 4 characters, as a hint).

Why does Chrome say it's "debugging this browser"?

Chrome shows that bar for any extension that uses its DevTools interface, which Browser Agent uses to click and type reliably. It's only there while the agent is working: it disappears when the task finishes or goes idle, and comes back when you send the next message. Clicking Cancel on it stops the task.

The agent asks for approval a lot

That's on purpose for anything consequential. You can switch off the kinds of actions you're happy for it to do alone in ⚙ Settings → Permissions → "Ask me before…".

Can it see my other tabs?

No. Each task works only in its own tab group. Your other tabs are never read or touched.

Why Browser Agent

Built for people who want an AI browser agent on their own terms.

🔌

Any model, always current

NVIDIA NIM, NanoGPT, OpenRouter, Anthropic, OpenAI, Gemini, Groq and more. Add a key and the provider's full model list appears, kept up to date.

🖥️

Fully local

Ollama, LM Studio, vLLM or llama.cpp on your own GPU. Installed models show up automatically.

Unfiltered models OK

Uncensored and abliterated models work. Safety comes from the policy engine, not from the model refusing.

🛑

You hold the brakes

It asks before purchases, logins, passwords, sending, deleting and more, with 11 separate switches.

🧩

CAPTCHA helper

Optional: a free local CAPTCHA model (CaptchaKraken, about 7 GB of GPU memory) clears Cloudflare, reCAPTCHA or hCaptcha checks so the task continues.

🔑

Private by design

Keys stay on your computer. The extension only talks to your own local server. No telemetry.

You decide what needs approval

A server-side policy checks every single action before it runs, whatever the model wants.

  • Purchases, payments, logins, password and card fields
  • Sending, posting, deleting, account and security changes
  • Accepting terms, page dialogs, scripts and uploads
  • Reading a site you haven't approved, even after a redirect or popup

All on by default. Untick what you're happy for it to do alone.

Gets past CAPTCHA checks

When a challenge blocks the page, Browser Agent hands just that part to CaptchaKraken v1.2, a free CAPTCHA model running on your own GPU, then carries on. You need Ollama, LM Studio or llama.cpp, about 7 GB of GPU memory and a 16k context. It only acts on genuine challenge widgets, and it's off by default. Setup guide

Set up in about two minutes

You need Chrome and Node.js 20+.

Start the server

Download the server zip from the latest release, unzip it, and run Start Browser Agent.cmd (Windows) or ./start.sh.

Add the extension

Install it from the Chrome Web Store (coming soon), or load the extension zip from the release as an unpacked extension.

Pair and go

Click Pair this browser, check that the code matches the server window, then type a task. That's it.
